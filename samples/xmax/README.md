# Sample XMAX customization

`Memo/` is a tiny customization in the XMetaL XMAX layout (`.ctm` behaviour
file, `.css` stylesheet, `.xsd` schema), for trying the importer without
real customizations at hand:

    cargo run --release -p xylem-customize --bin xylem-import -- samples/xmax/Memo out/memo

or File › Import XMAX customization in the editor (choose `Memo.ctm`).
`memo-sample.xml` is a document for it.
